# UI Design Rules

## Color Palette
- **Primary**: #000000 (Black) / #FFFFFF (White in Dark Mode)
- **Secondary**: #333333 (Dark Gray) / #CCCCCC (Light Gray in Dark Mode)
- **Accent**: #111111 (Almost Black) / #EEEEEE (Almost White in Dark Mode)

## Style Guidelines
- **Theme**: Modern AI SaaS Platform
- **Aesthetic**: Minimalist Design, Glassmorphism Effects, Smooth Animations
- **Typography**: Modern Sans Serif (e.g. Inter)
- **Layout**: Clean spacing, ample whitespace, rounded corners.

All UI components must adhere strictly to these color variables and the overall aesthetic. Use Tailwind CSS effectively to apply these tokens globally.
